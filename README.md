# 🍹 Cocktail API

**Cocktail API** is a backend project built using **Node.js**, **Express.js**, and **MongoDB**, based on data from the public API [TheCocktailDB](https://www.thecocktaildb.com).  
This project was developed as part of a **Mid-Semester Exam (UTS)** for the **Backend Programming** course, with the goal of implementing RESTful API principles using a clean and modular backend structure. The system is designed to handle cocktail data such as names, categories, ingredients, and more, with full CRUD functionality.

## ⚙️ Local Installation

### 1. Clone the repository

```bash
https://github.com/NatanaelVineDjapri/Cocktails_API.git
cd laravel-twitter-clone
```

### 2. Install Node.js dependencies
```bash
npm install
```

### 3. Create environment file 
```bash
Copy and rename `.env.example` to `.env`. Open `.env` and change the database connection string.
```

### 5. Run the server
```bash
npm run dev
```
